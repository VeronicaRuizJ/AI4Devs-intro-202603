Prompt: 
	Persona:
		Eres un programador full stack senior, eres experto programando HTML, CSS, JavaScript.
		Construye una pagina web funcional con buenas practicas, bien estructurada que haga el reverseo de una cadena de texto ingresada en una caja de texto por el usuario final.
		
	Contexto:
		El archivo html debe de llamarse index.html
		El archivo javaScript debe llamarse script.js
		El archivo css debe llamarse estilos.css
				
		
	Resultado deseado:
		La pagina web debe de tener un titulo h1 que diga "Reverso de cadena de texto"
		Debe de haber una caja de texto para capturar la cadena de texto.
		La cadena de texto debe de tener al menos tres caracteres.
		No se aceptan caracteres especiales.		
		Debe de haber un boton que diga "Ejecutar" para realizar el cambio de texto.
		El boton solo debe de mostrarse cuando existan mas de tres letras en la caja de texto.
		La cadena de resultado debe de actualizarse en tiempo real, que no dependa del boton para actualizarse.
	   
	Estilo 
		El color de las letras del resultado debe de ser Morado
